ההתראה החכמה שלך 📞

שיחה למספר הבוט שלא נענתה הופכת אוטומטית לפנייה בוואטסאפ. מתקינים פעם אחת על הטלפון של הבוט — וזה עובד לבד.
לבוט יש מספר וטלפון משלו — טלפון ייעודי שתמיד דלוק. כשלקוח מתקשר למספר הבוט ואין מענה, מהיום המערכת שולחת לו אוטומטית הודעת וואטסאפ אישית בשמך ומתחילה איתו את השיחה — ואתה ממשיך משם רגוע. אפס לקוחות אבודים, בלי שתעשה כלום. כל מה שצריך: להתקין פעם אחת אפליקציה קטנה וחינמית על הטלפון של הבוט, ולמלא בה 2 התראות לפי המדריך. הכול כאן — צעד-צעד.
📱 "הטלפון של הבוט" = הטלפון שבו נמצא הסים הייעודי של הבוט (אפשר טלפון ישן) — תמיד דלוק ומחובר ל-wifi. שם מתקינים את האפליקציה, כי רק הוא מצלצל כשמתקשרים למספר הבוט. הסים חייב להישאר פעיל.

ההתראה הראשונה — "שיחה שלא נענתה / שנדחתה" ☎️

זו ההתראה החשובה: כשמישהו מתקשר למספר הבוט והטלפון הייעודי לא נענה (וזה תמיד — אין שם מי שיענה), היא שולחת לו אוטומטית את הודעת הפתיחה שלך בוואטסאפ. בונים אותה פעם אחת.

1
יוצרים מאקרו חדש
פותחים את MacroDroid → לוחצים על + Add Macro (הוסף מאקרו) למעלה. בשם המאקרו כותבים: שיחה שלא נענתה / שנדחתה.
2
בוחרים מתי זה יקרה — שני טריגרים
צריך שזה יקרה גם כשלא ענית וגם כשדחית. מוסיפים שני טריגרים לאותו מאקרו:
• לוחצים Add Trigger → קטגוריה Phone (טלפון) → בוחרים Call Missed (שיחה שלא נענתה) → כשנשאל לאילו מספרים, בוחרים Any Number (כל המספרים).
• לוחצים שוב Add Trigger → אותה קטגוריה → הפעם Call Ended (שיחה הסתיימה) → בוחרים Incoming (נכנסת), ושוב Any Number (כל המספרים).
למה שניים: בחלק מהמכשירים שיחה שאתה דוחה לא נרשמת כ"לא נענתה" — אז הטריגר השני סוגר את הפינה. המערכת שולחת ללקוח הודעה פעם אחת בלבד גם אם שניהם נדלקו, אז אין כפילות.
3
בוחרים מה יקרה (פעולה)
לוחצים Add Action (הוסף פעולה) → Connectivity (קישוריות) → HTTP Request (בקשת HTTP). למעלה יש לשוניות — ממלאים שתיים:
📑 לשונית Settings (הגדרות): Request method (שיטת בקשה) = POST · Enter url (כתובת) = ערך מס' 1 (הכתובת המלאה — מסתיימת ב-/webhook/missed-call).
📑 לשונית Content Body (גוף התוכן): Content type = application/json, בוחרים Text, ובשדה הטקסט הגדול מדביקים בדיוק —
{"secret":"‹הקוד הסודי — ערך 2›","number":"[call_number]"}
🔸 רק במקום ‹הקוד הסודי — ערך 2› מדביקים את הקוד הסודי מעמוד 1 (בעותק שאורי שולח — הוא כבר מודבק).
🔸 את [call_number] משאירים בדיוק כמו שהוא — זו "המילה הקסומה" של MacroDroid שמתחלפת לבד למספר המתקשר. לא נוגעים בה, ולא כותבים עברית בתוך השורה.
💡 שים לב: הקוד והמספר כבר נמצאים בתוך השורה הזו — אין שדה נפרד ל"סיסמה" או ל"מספר". הכול חי בתוך הטקסט של "גוף התוכן".
🔴 אזהרה: במסך Settings יש שדות Username / Password תחת Basic Authorization — משאירים אותם ריקים ואת "Use authorization" לא מסמנים. הקוד שלנו הולך רק ל"גוף התוכן", לא לשדה Password.
🔴 כל השורה באנגלית: אם נכנסה מילה בעברית באמצע — מוחקים הכול ומדביקים מחדש.
4
שומרים
לוחצים על סימן ה-✓ למעלה כדי לשמור את המאקרו. זהו — ההתראה הראשונה מוכנה! 🎉
טיפ: אם משהו לא ברור באמצע — אפשר לצאת ולחזור; MacroDroid שומר את מה שהתחלת. אין מה לשבור.

ההתראה השנייה — "בדיקת חיים" 💓

התראה קטנה ששולחת למערכת "אני פעילה" כל כמה שעות. כך, אם משהו משתבש בטלפון — יודעים על זה מיד ומטפלים, בלי שתאבד פניות בשקט. בונים אותה בדיוק כמו הראשונה, רק עם 2 הבדלים קטנים.

1
מאקרו חדש בשם "בדיקת חיים"
+ Add Macro → שם: בדיקת חיים.
2
טריגר: כל 6 שעות
Add Trigger → קטגוריה Date/Time → Regular Interval (מרווח קבוע) → בוחרים כל 6 שעות.
3
פעולה: אותו HTTP Request, עם גוף אחר
Add Action → Connectivity → HTTP Request. בדיוק כמו קודם: לשונית Settings (הגדרות) — Request method = POST, Enter url = ערך מס' 1, ו"Use authorization" מכובה. לשונית Content Body (גוף התוכן) — Content type = application/json, ובשדה הטקסט מדביקים (שים לב — בלי [call_number], ועם heartbeat):
{"secret":"‹הקוד הסודי — ערך 2›","heartbeat":true}
מדביקים את אותו קוד סודי. כאן אין מספר מתקשר — זו רק בדיקה תקופתית. כל השורה באנגלית. שומרים ב-✓.

בודקים שהכול עובד ✅

4
בדיקה אחת ואתה מסודר
ממספר כלשהו — מתקשרים למספר הבוט ומניחים שהטלפון הייעודי יצלצל בלי מענה (ואם בא לך, נסה גם לדחות משם). תוך כמה שניות המתקשר אמור לקבל בוואטסאפ את הודעת הפתיחה שלך. קיבל? סיימת — הכול עובד! 🎉
לא הגיעה הודעה? בדוק 3 דברים: (1) שחיסכון הסוללה כבוי (שלב 2 בעמוד 1); (2) שהקוד הודבק בדיוק, בלי רווחים מיותרים; (3) שהכתובת הועתקה במלואה. עדיין תקוע? שלח הודעה והכול ייפתר.
שקט נפשי 🔒: האפליקציה רק מזהה שיחות שלא ענית להן או שדחית, ומפעילה את ההודעה — היא לא קוראת הודעות, לא ניגשת לתמונות, ולא עושה שום דבר אחר. הכול רץ אצלך בטלפון, בשליטה מלאה שלך, וההודעה שנשלחת היא בדיוק הנוסח שלך — בשמך.
הבוט על טלפון ייעודי משלו? סיימת — דלג על העמוד הבא. (הוא רלוונטי רק אם שמת את סים הבוט בטלפון האישי שלך, ואז מסנן כך שחברים/משפחה שמורים לא יקבלו הודעה.) ⬅️

שלב אופציונלי — רק למספרים לא מזוהים 🔕

🟢 הקמת לפי ההמלצה (טלפון ייעודי לבוט)? דלג על העמוד הזה לגמרי — בטלפון של הבוט אין אנשי קשר אישיים, אז ממילא כל מתקשר מקבל הודעת פתיחה, ואין מה לסנן. העמוד הזה רלוונטי רק במקרה הנדיר שבחרת לשים את סים הבוט כסים-שני בטלפון האישי שלך — אז הוא גורם לבוט לשלוח פתיחה רק למספרים שלא שמורים אצלך, ולדלג על אנשי קשר מוכרים.

איך זה עובד: MacroDroid יודע לתת לנו את שם המתקשר. מספר שמור → הוא מחזיר את השם; מספר לא שמור → הוא מחזיר את המספר עצמו. אז התנאי פשוט: לשלוח רק כשהשם זהה למספר (= לא מזוהה).
1
פותחים את מאקרו השיחה לעריכה
נכנסים למאקרו "שיחה שלא נענתה / שנדחתה" (לא ל"בדיקת חיים" — אותו לא נוגעים).
2
מוסיפים תנאי "If" מעל פעולת ה-HTTP
לוחצים Add Action → קטגוריה Conditions/Loops (תנאים/לולאות) → If clause. זה מוסיף אוטומטית גם End If מתחת.
3
בוחרים השוואה: Compare Values
בתוך ה-If לוחצים + (הוסף תנאי) → בוחרים Compare Values (השוואת ערכים). ממלאים בדיוק כך — הכול באנגלית:
Value 1: [call_name] Operator: Is equal to ( = ) Value 2: [call_number]
מקלידים את שני הטוקנים עם הסוגריים המרובעים, בדיוק כפי שכתוב.
4
מוודאים שה-HTTP בפנים — ושומרים
פעולת ה-HTTP Request צריכה להיות בין ה-If clause ל-End If (אם צריך — גוררים אותה פנימה). שומרים ב-✓.
זהו. מעכשיו: מספר שמור → הבוט שותק. מספר לא מזוהה → שולח הודעת פתיחה. רוצה לבדוק? התקשר ממספר לא שמור (לא עונים) → אמורה להגיע הודעה. התקשר ממספר שמור (לא עונים) → לא אמורה להגיע.
נתקעת? יש שאלה? שלח הודעה ונפתור תוך דקות.
